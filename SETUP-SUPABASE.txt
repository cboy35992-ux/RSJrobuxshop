RSR SHOP V7 MARKETPLACE

V6 features retained:
- Supabase permanent database and receipt storage
- Customer accounts, dashboard, unread messages
- Stock reservation, password reset, email verification
- Order timeline, verified reviews and FAQ

V7 upgrades:
- Dark/light theme
- Admin online/offline support indicator
- Promo code system
- Marketplace feature section
- Admin promo manager
- Sales analytics database view
- Improved customer dashboard banner
- Server-side promo validation

SETUP:
1. Create a Supabase project.
2. Run supabase-schema.sql in Supabase SQL Editor.
3. Add the required environment variables to Render.
4. Upload project files to GitHub.
5. Deploy latest commit on Render.
